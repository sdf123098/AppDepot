AppDepot 隐私政策

生效日期：2026 年 9 月 14 日

本隐私政策适用于 AppDepot（以下简称“本应用”），由 Micaftic（以下简称“我们”）维护。

一、我们收集的信息

本应用不要求用户注册账号，也不会主动收集用户姓名、电子邮件地址、电话号码、通讯录、精确位置、照片、音视频、支付信息或广告标识符。

本应用不包含由我们自建的广告、用户画像、分析、遥测或行为跟踪系统。

在使用网络功能时，相关服务提供商可能自动接收到常规技术信息，例如 IP 地址、User-Agent、请求时间、网络请求地址以及 Windows 和应用版本信息。这些信息由相关网络服务提供商按照其自身隐私政策处理。

二、应用功能产生的数据

1. 商店搜索和下载

当用户搜索应用、查看应用详情、获取下载地址或下载更新时，本应用会向 Microsoft Store 相关服务及相应下载服务发送必要的搜索词、产品标识符、市场、语言、处理器架构和网络请求信息。

2. 应用更新

本应用会访问 GitHub Releases 检查 AppDepot 更新。GitHub 可能按照其自身隐私政策处理 IP 地址、User-Agent、请求时间和请求信息。

3. 可选的 AI 翻译功能

只有在用户主动配置并点击翻译时，本应用才会将应用描述、目标语言和用户填写的翻译指令发送到用户配置的 AI 服务。

该服务地址由用户自行填写。本应用不会将这些内容发送到 Micaftic 的自建服务器。用户应在使用前阅读所选 AI 服务提供商的隐私政策。

用户配置的 API 密钥仅保存在当前 Windows 用户的 Windows 凭据保管库中，并用于向用户指定的服务发送翻译请求。本应用不会将 API 密钥上传到 Micaftic 的服务器。

三、本地保存的信息

本应用可能在用户设备本地保存以下设置：

  • 界面语言、市场和主题设置；
  • 下载连接模式和代理设置；
  • 首选处理器架构；
  • 更新检查设置；
  • AI 翻译服务地址、模型和翻译指令；
  • 应用图标选择；
  • 运行、安装和崩溃诊断日志。

这些信息默认保存在用户设备本地，不会由本应用主动上传到 Micaftic 的服务器。诊断日志可能包含应用版本、Windows 版本、错误信息、文件路径、产品标识符或请求相关信息。

四、信息使用目的

我们仅使用相关信息来提供应用搜索、查看、下载、安装和更新功能，按用户要求执行 AI 翻译，保存用户的本地应用设置，诊断应用错误和改进稳定性，以及维护应用安全和正常运行。

我们不会出售、出租或将用户信息用于广告营销。

五、第三方服务

本应用可能连接 Microsoft Store 及相关 Microsoft 服务、GitHub Releases、应用下载所使用的内容分发或存储服务，以及用户自行配置的 AI 翻译服务和代理服务器。第三方服务对数据的处理由其各自的隐私政策和服务条款约束。

六、数据保存期限和删除

Micaftic 不在自建服务器上保存用户个人信息。用户可以通过卸载应用、清除 AppDepot 本地应用数据和日志，或在应用设置中删除翻译服务配置来移除本地保存的信息。

第三方服务可能按照其自身的日志和数据保留政策保存网络请求或用户提交的内容。

七、数据安全

本应用使用 HTTPS 访问支持 HTTPS 的网络服务。AI API 密钥使用 Windows 凭据保管库保存。用户应确认所配置的代理服务器、AI 服务和其他第三方服务可信，并避免将敏感个人信息输入搜索框、翻译指令或其他可发送到第三方服务的内容中。

八、儿童隐私

本应用不是面向儿童设计的服务。我们不会故意收集儿童的个人信息。

九、隐私政策变更

我们可能根据功能、法律或服务变化更新本隐私政策。更新后的版本将在本页面发布，并更新生效日期。
